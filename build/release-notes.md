## NovelReader 0.10.0

Cette version s'installe toute seule en arrière-plan (fermez NovelReader et rouvrez-le). Pour le watch party, tout le monde doit avoir la 0.10.0.

### Watch party
- **Rejoindre sans avoir la même source** : si votre ami regarde depuis une source que vous n'avez pas, NovelReader cherche le même épisode dans vos sources à vous, et la synchronisation continue. Un bouton **Installer …** dans le panneau 👥 installe la source de votre ami en un clic.
- **Réactions** 😂 ❤️ 😮 😱 🔥 👏 😢 : passez la souris sur la vidéo et cliquez, elles s'envolent sur l'écran de tout le monde avec votre nom.
- **Plein écran avec le chat** : en séance, le bouton ⛶ (ou F, ou double-clic) met le lecteur en plein écran avec les messages qui s'affichent sur la vidéo. **Entrée** pour écrire un message sans quitter le plein écran, Échap pour annuler.
- **Reconnexion automatique** : si la connexion d'un invité saute, il revient tout seul dans la séance. Si le PC de l'hôte disparaît, le premier invité devient l'hôte et les autres le rejoignent automatiquement.
- L'hôte peut **quitter en laissant la séance continuer** : « Quitter (Sara devient l'hôte) ». « Terminer la séance » reste disponible.
- **Vocal** : le son du film baisse tout seul quand quelqu'un parle (désactivable), et l'option **Appuyer pour parler** (maintenir V) coupe votre micro le reste du temps.

### Corrections
- Watch party : avancer dans la vidéo pouvait vous ramener en arrière (la séance attendait l'ancien endroit). Un saut dans la vidéo est maintenant suivi par tout le monde.
- Les différentes qualités ne s'affichent plus en boutons sous le lecteur : elles sont seulement dans le menu **Qualité**.

### Installation
Téléchargez `NovelReader-Setup-0.10.0.exe` ci-dessous. Windows SmartScreen peut afficher un avertissement car l'installeur n'est pas signé : « Informations complémentaires » › « Exécuter quand même ».
