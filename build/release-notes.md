## NovelReader 0.7.0

Si vous avez une version précédente, celle-ci s'installe toute seule (une bannière propose de redémarrer).

### Nouveau : Regarder ensemble (watch party)
Regardez un anime, une série ou un film à plusieurs, chacun sur son PC.

- Dans Anime, Séries ou Films, cliquez sur **👥 Regarder ensemble** (en bas de la barre latérale), puis **Lancer un watch party** : un code de 6 lettres s'affiche.
- Vos amis cliquent sur **Regarder ensemble**, entrent le code et **Rejoindre**.
- Ouvrez un épisode : tout le monde passe au même épisode. Lecture, pause, avance et retour sont partagés dans les deux sens, et un petit chat permet de discuter.
- Chacun lit la vidéo depuis ses propres sources : installez la même source (le titre n'a pas besoin d'être dans la bibliothèque des autres).
- La connexion est directe entre les PC ; un service public gratuit (PeerJS) sert seulement à les mettre en relation avec le code. Sur certains réseaux très fermés (entreprise, certains partages 4G), la connexion peut échouer.

### Installation
Téléchargez `NovelReader-Setup-0.7.0.exe` ci-dessous. Windows SmartScreen peut afficher un avertissement car l'installeur n'est pas signé : « Informations complémentaires » › « Exécuter quand même ».
