## NovelReader 0.11.1

Cette mise à jour s'applique **sans fermer NovelReader** (la fenêtre se recharge en une seconde quand vous n'utilisez pas l'app, ou avec le bouton de la bannière).

### Langues pour les animes, séries et films (comme dans Livres)
- **Recherche globale** (Anime, Séries, Films) : des pastilles de langue au-dessus des résultats, comme dans Livres. Par défaut : anglais, multilingue et la langue de l'app ; cliquez pour ajouter ou retirer une langue (par exemple Français). Seules les sources des langues choisies sont interrogées, donc la recherche est plus rapide. Le choix est retenu pour chaque section.
- Chaque résultat indique la langue de ses sources.
- **Catalogue des sources vidéo** (Sources › Tout charger) : les mêmes pastilles pour n'afficher que les sources des langues qui vous intéressent.

### Installation
Téléchargez `NovelReader-Setup-0.11.1.exe` ci-dessous. Windows SmartScreen peut afficher un avertissement car l'installeur n'est pas signé : « Informations complémentaires » › « Exécuter quand même ».
