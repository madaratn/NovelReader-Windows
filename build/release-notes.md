## NovelReader 0.8.0

Si vous avez une version précédente, celle-ci s'installe toute seule (une bannière propose de redémarrer).

### Nouveau : vocal dans le watch party
- Dans **👥 Regarder ensemble**, une fois dans une séance : **🎙 Rejoindre le vocal** pour parler avec les autres pendant le film.
- **Couper le micro**, **volume des voix** réglable, et la personne qui parle est mise en évidence dans la liste.
- La voix passe directement entre les PC, comme la synchronisation de la vidéo ; rien n'est enregistré.
- Conseil : mettez un casque, pour que le son du film ne repasse pas dans votre micro.
- Si le micro est refusé, vérifiez Paramètres Windows › Confidentialité et sécurité › Microphone › « Autoriser les applications de bureau à accéder au microphone ».

NovelReader demande seulement le micro (jamais la caméra).

### Installation
Téléchargez `NovelReader-Setup-0.8.0.exe` ci-dessous. Windows SmartScreen peut afficher un avertissement car l'installeur n'est pas signé : « Informations complémentaires » › « Exécuter quand même ».
