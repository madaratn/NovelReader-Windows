## NovelReader 0.16.0 — les vidéos sur Android 📱🎬

### Android : animes, séries et films
- Le moteur vidéo du PC tourne maintenant **dans le téléphone** : les mêmes extensions (Aniyomi), les mêmes dépôts, sans PC allumé.
- Recherche, fiches, liste des épisodes, choix du serveur et de la qualité, sous-titres des sources, reprise là où vous vous étiez arrêté.
- **Plein écran** : la vidéo passe en paysage, sans les barres d'Android, et l'écran reste allumé. Le bouton retour quitte le plein écran.
- Testé sur un émulateur Android avec de vraies sources : AnimeOnsen, LMAnime, Anichi, Anikoto, AnimeParadise, AnimeSogo (6 sur 7 essayées), et lecture dans le lecteur de l'application.
- Pas encore sur Android : les torrents, le cast vers la télé, les téléchargements, les sous-titres IA et les sites protégés par Cloudflare (sur PC, c'est FlareSolverr qui s'en occupe).

### Installation
- Téléchargez **NovelReader-0.16.0.apk** depuis cette page.
- Cette version est signée avec la nouvelle clé : **désinstallez une fois l'ancienne application** avant d'installer celle-ci. Les versions suivantes s'installeront par-dessus.

### Windows
- Rien ne change sur PC (mise à jour de l'interface sans redémarrer).
