# NovelReader

**NovelReader v0.22.0** is a multilingual reading and video application for Windows and Android, with experimental Android TV and iOS targets.

**Project status: family-and-friends beta.** The app is not a security-certified plugin sandbox or a public streaming service. Use trusted sources and content you have the right to access.

## Download

Use the assets from the [official GitHub Releases](https://github.com/madaratn/NovelReader-Windows/releases):

- **Windows:** `NovelReader-Setup-<version>.exe` (installer; currently not code-signed).
- **Android:** `NovelReader-<version>.apk` (install on phone/tablet or compatible Android TV). Keep the same signing certificate when updating.
- **iOS:** an unsigned IPA is generated by CI for development; **not yet recommended for relatives' iPhones**.

Before distributing to others, follow the [family beta acceptance checklist](docs/FAMILY-BETA.md). Back up libraries and progress first.

## What it does

- **Books:** source extensions (LNReader-compatible), global search, shelves, reader, offline chapters, bookmarks/notes, translation, read aloud.
- **Anime, series and movies:** extension-driven discovery and streaming, server/quality selection, remembered playback, local videos and offline downloads on supported devices.
- **Watching together:** cross-PC Watch Party with synchronized playback, chat, voice and optional camera.
- **Playback tools:** subtitles and translation, Chromecast/DLNA, selected external metadata services (AniList/MyAnimeList). Availability depends on platform, source and codec.
- **Cross-device:** local Wi-Fi pairing by QR code with Windows for library/progress sync and 'Continue on phone'. The Windows PC must be running NovelReader; do not expose the pairing port to the internet.
- **Languages:** French/English UI and other language support. Video-source availability can change without warning.

## Develop

Requires Node.js 22 (and the appropriate platform SDKs for native packaging).

```bash
npm install
npm run start
```

Validation commands:

```bash
npm run typecheck
npm run check:i18n
npm run test:unit
npm run build
npm run test:ui
npm run build:android
npx playwright test -c playwright.android.config.ts
```

Windows packaging uses `npm run dist`; Android uses `npm run apk` (or the GitHub Actions workflow). Android builds use Java 17, Gradle and an Android SDK; the video engine requires additional preparation.

## Structure

- `src/features/`: books, media, search, reader, downloads, settings, sync, Watch Party and phone link.
- `src/lib/`, `src/platform/`, `src/ui/`: shared logic, platform integration and UI.
- `electron/`: desktop process, update paths, source engine relay, audio, video, profiles and local file access.
- `android/`: Capacitor shell, Kotlin native plugins and local video/source engine.
- `ios/`: iOS Capacitor project (development target).
- `tests/unit/`, `tests/ui/`, `tests/android/`: automated coverage.
- `.github/workflows/`: builds, UI tests, Android smoke tests and periodic source checks.

## Updates and releases

- Windows installer: `.github/workflows/build-windows.yml`; on PRs, build must pass typecheck, translation checks and unit tests.
- Android APK: `.github/workflows/build-android.yml`; publication is gated on native unit tests **and an emulator smoke test**.
- New version and release notes: change `version` in `package.json` and `build/release-notes.md` together.
- App builds do **not** prove all community sources work. Check sources on real devices before inviting testers.

## Security and legal caveats

- Community extensions can run code. **Only use trusted extensions**. Full extension isolation and signing improvements are tracked in [family beta checklist](docs/FAMILY-BETA.md).
- Phone pairing operates over **unencrypted local HTTP**, protected by a pairing code. Only use it on a trusted Wi-Fi/LAN.
- Video and novel sources are supplied by third parties; their availability, authentication, copyright terms and geographical restrictions are outside this project's control. No DRM bypass is promised.
